# chacha-bot

일상 속 당연한 것들에 숨은 기술을 함께 파헤쳐 보는 AI 챗봇.
기능은 하나예요: **채팅을 보내고 보기**.

## 레포 구조

```
chacha-bot/
├─ frontend/   웹 클라이언트 (스택 미정)
├─ backend/    API 서버 (스택 미정)
├─ design/     디자인 토큰·컴포넌트 CSS·아이콘·핸드오프 문서
├─ docs/       결정 기록 등 프로젝트 문서
└─ .github/    Issue·PR 템플릿
```

각 폴더의 README에 해당 영역의 현재 상태와 정해야 할 것들을 적어 두었어요.

## 개발 방식

- Issue를 먼저 만들고, 이슈마다 브랜치를 따서 PR로 `main`에 합쳐요(GitHub Flow).
- `main`에는 직접 push할 수 없어요. 자세한 규칙은 [CONTRIBUTING.md](CONTRIBUTING.md)를 보세요.
