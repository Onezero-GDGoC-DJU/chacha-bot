엘리베이터는 왜 내가 누른 층으로 바로 오지 않을까?

엘리베이터는 요청이 들어온 순서대로 움직이지 않아요. 여러 층의 요청을 한꺼번에 보고 전체 이동 거리를 줄이는 스케줄링 알고리즘을 쓰기 때문이에요.

대표적인 방식

  1. FCFS: 들어온 순서대로 처리해요. 단순하지만 위아래로 오가는 거리가 길어져요.
  2. SCAN: 한 방향으로 끝까지 가면서 요청을 처리하고, 끝에 닿으면 방향을 바꿔요.
  3. LOOK: SCAN과 같지만, 그 방향에 더 이상 요청이 없으면 바로 돌아와요.

이 알고리즘은 운영체제의 디스크 스케줄링에서도 똑같이 쓰여요. 디스크 헤드를 엘리베이터, 읽을 위치를 층이라고 보면 돼요.

python 
def look(requests, head):
    up = sorted(r for r in requests if r >= head)
    down = sorted((r for r in requests if r < head), reverse=True)
    return up + down

print(look([2, 9, 4, 7, 1], head=5))  # [7, 9, 4, 2, 1]

현재 5층에서 위로 가는 중이라면 7층, 9층을 먼저 들른 뒤 내려오면서 4층, 2층, 1층 순서로 처리해요.

그럼 OS의 CPU 스케줄러랑도 비슷한 거야?

비슷한 부분이 많아요. 둘 다 한정된 자원(엘리베이터, CPU)을 여러 요청이 나눠 써야 하는 문제라서, "누구를 먼저 처리할까"를 정하는 규칙이 핵심이에요.
